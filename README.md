# Portale — Sovranità Digitale Europea

Portale di consultazione di una knowledge base (grafo di entità, relazioni e fonti) sul
dibattito relativo alla **sovranità digitale europea**: cloud sovrano, autonomia tecnologica,
semiconduttori e AI. Costruito con [graphify](https://github.com/) a partire da fonti pubbliche
(report EuroStack – Bertelsmann Stiftung/CEPS, documenti della Commissione europea, newsroom
ufficiali e rassegna stampa).

👉 **Sito:** apri `index.html` (single-page, autoconsistente, nessuna dipendenza esterna).
